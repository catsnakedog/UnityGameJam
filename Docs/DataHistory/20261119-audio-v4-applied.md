# 사운드 표 v4 적용과 검증

- 기존 SoundManager 프리팹에 표의 01~32번 SoundCue를 연결했다. 10번은 기존 `audio.cue.ui-click`을 재사용했다. SFX_Default와 Ambience_Loop은 예제이며 별도 역할이다. 데이터 ID·에셋 경로·GUID는 [SoundCue 명세](../DataSpecs/SoundCue.md)에 있다.
- MP3 24개는 공유 원본과 바이트가 일치한다. 25~32번은 원본 표에서 미제작이므로 호출 지점과 빈 Cue를 연결했다. 음악에는 전용 Music 볼륨을, 효과에는 UI/SFX 볼륨을 적용한다. 기존 사용자 볼륨 키를 사용한다.
- 별도 프롤로그 씬이 없어 02번은 시작 인물 선택과 파밍 준비 구간에 적용했다. 파밍 BGM은 실제 제한시간이 시작될 때 한 번 재생하고 현재 프로젝트의 30초 타이머가 끝날 때 종료한다. 상위 두 기존 엔딩은 Victory, 미완성 엔딩은 Fail을 사용한다. 별도의 전멸 엔딩 판정은 현재 게임에 없다.
- Unity Play에서 타이틀 → 인물 선택 → 파밍 → 벙커 흐름, 두 엔딩, 실제 버튼·획득·카운트다운·해치, 노트북 알림과 BGM 감쇠/복구, 텐트 입실·기상·기절, 정시·습격·문 돌파·근접 승패·좀비 처치를 확인했다. 32개 참조, 재생 가능한 효과음 핸들, 진척음의 동일 프레임 중복 억제와 빈 Cue의 무음 처리도 확인했다. 검증은 AudioSource·클립·상태 기준이다.
