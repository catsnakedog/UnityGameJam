# 작업방 정원과 방 인원판

`data.bunker.rules`의 기존 정본에 기획·프로그래밍·아트 작업방 정원 `workRoomCapacity`를 추가했다. 한 방에 3명이며 수면실은 `sleepingRoomCapacity`를 계속 사용한다. 기존 레지스트리와 코드·설정에서 작업방 정원의 다른 정본을 찾지 못했다. [필드 명세와 정본](../DataSpecs/BunkerRules.md)

여섯 방의 인원판은 입실자와 이동 예약을 같은 자리 판정으로 집계한다. 거실·전투 장소는 정원 제한이 없어 분모가 ∞다. 좀비 점령 중에는 좀비 아이콘과 x/x를 표시하며 마지막 점령자가 사라지면 현재 인원을 다시 표시한다. 인원판 왼쪽은 원화의 위쪽 벽선에 맞춘다.

Addressables 콘텐츠 빌드와 Unity Play에서 세 작업방 각각의 세 자리 예약, 네 번째 거절, 목적지 변경 후 빈자리 재사용, 두 점령자가 차례로 해제될 때의 전환을 확인했다. [게임 화면](../Images/ShelterRoomHeaders.png)
