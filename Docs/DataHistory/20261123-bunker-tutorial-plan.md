# 벙커 튜토리얼 방송 계획

2026-11-23 KST · UnityGameJam · data.shelter.dialogue · planned

기존 주최측 14행은 복도 튜토리얼 한 곳에서 재생한다. 타이틀에서 튜토리얼을 선택한 회차는 파밍 전 조작 안내와 벙커 도착 후 시설 안내로 나눈다. 생존자·좀비 대사와 기존 방송 ID를 보존하고 같은 ShelterDialogue.csv의 상황 키로 두 구간을 구분한다. Assets, ProjectSettings, Docs와 목록의 planned 항목을 확인했다. 다른 튜토리얼 대사 정본은 없다. 기존 data/catalog를 통해 두 씬이 읽으며 회차 표시만 메모리에 보관한다.
