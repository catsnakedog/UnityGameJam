# 파밍 시작 운반과 공용 동작 적용 계획

기존 파밍 규칙(data.farming.rules)의 방 인원은 현재 3·2·1명이고, 모든 사람 ID를 방에 배정한 뒤 빈 인벤토리를 만든다. 새 회차에서는 기존 Person 중 person_01을 하나 들어서 시작하고 거리순 325·324·323호에 나머지 다섯 명을 2·2·1로 배정한다.

- FarmingRules.asset의 시작 인물 ID와 기존 방별 인원으로 배치한다. 해당 ID의 외래키·운반 비용은 data.farming.pickups의 기존 행으로 검증한다. 시작 대상도 일반 획득·내려놓기·재획득·투입 경로를 따른다. 벙커로 넘기는 목록은 투입한 개체로 확정한다.
- 등록 목록의 planned, Assets·ProjectSettings·Docs에서 시작 운반, person_01, roomSpawns, Inventory와 관련된 경로를 대조했다. 시작 인물 설정은 기존 정본에 추가한다. 인물 목록과 무게, 용량, 등급 정본을 재사용한다.
- 파밍의 사람·플레이어 표시에는 Survivor 프리팹의 ID별 Artwork와 Aseprite 클립을 재사용한다. 소스 그림, 클립 배열 및 콘텐츠 목록을 복제하지 않는다. 벙커와 파밍에 공통 프레임 선택을 적용한다.
- 검증 항목은 시작 운반 비용 및 미투입 상태, 방 배정과 ID 중복, 실제 이동 및 운반, 놓기·재획득·투입, 회차 재시작, 공용 애니메이션 표시다.
