# 파밍 준비와 작업 표시 실행 기록

Unity 6000.3.28f1에서 `data.farming.rules.preparationDuration`을 15초로 저장하고 Windows Addressables를 갱신했다. 준비 중 이동과 방 출입, 획득·투입 차단, 준비 종료 후 기존 파밍 시간 시작을 확인했다. [FarmingRules 명세](../DataSpecs/FarmingRules.md) · [파밍 Play 기록](../Farming/Verification-SideView.txt)

벙커에서는 작업 분야 아이콘과 개인 기여량을 기존 Survivor 프리팹에 연결했다. 세 분야, 100% 상한, 미작업 표시, 숫자키 선택과 이동 시 선택 해제를 확인했다. 기절자에게 회복제를 사용했을 때 거부되며 재고와 멘탈이 유지됐다. [벙커 검사](../Bunker-play.txt) · [카메라 검사](../ShelterCamera-checks.txt) · [사용 데이터와 중복 조사](20261119-work-progress-feedback.md)
