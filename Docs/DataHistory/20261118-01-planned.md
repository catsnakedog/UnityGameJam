# Farming 데이터 최초 설계 · planned

- 프로젝트: UnityGameJam / 6000.3.28f1
- 기록 시각: 2026-11-18 +09:00
- 근거: 사용자 요청의 파밍 단계만 구현. 기존 게임 데이터/로더 없음.
- 기존 사용자 변경: UniversalRP, ProjectSettings 및 삭제된 HubForceResolve 파일은 보존.
- 정본: `Assets/Settings/Farming/FarmingData.csv`, 스키마 v1, UTF-8, `id,type,weight`.
- type: Person 또는 Item. weight는 정수 슬롯 수. 사람 2~4, 물자 1~2. ID 중복/공백 금지.
- 사람 6개 레코드(2,3,4,2,3,4칸), 물자 6종(1~2칸). 씬에는 물자 12개 배치.
- CSV 전체 검증 후 FarmingDatabase SO 갱신. 기존 행이 누락되면 자동 삭제하지 않고 실패. 명시적 삭제는 후속 데이터 작업으로 처리.
- 설정 SO: FarmingRules. 사용자 확정값 Duration=60초, Capacity=4. 제안 초기값 MoveSpeed=5.8m/s, InteractionRadius=2m, DropDistance=1.6m, ThrowDuration=0.45초, FadeDuration=0.5초, ThrowArc=1.5m, WarningSeconds=10초, MapHalfExtents=(11,8).
- 주소: `data/farming/database`, `data/farming/rules`. 그룹 Farming Local. 생성 전 GUID 없음.
- 수명: FarmingSession 소유 FarmingDataLoader가 비동기 로드·동시 호출 공유·해제. 소비자는 ID 조회/읽기 전용 설정 사용. 런타임 상태는 별도.
- 소비자: FarmingSession(시간/종료/투입), FarmingPlayer(이동/거리/운반), FarmingPickup(무게/연출), FarmingHud(칸/시간/집계).
- 배치: 기존 Scenes/Settings 재사용. 새 공용 Scripts, Editor, Prefabs, Materials, Art, Fonts, Docs 루트는 파일 종류별로 사용.
- 검증 예정: CSV 오류의 원자성, 4칸 경계, 6명, 이동/충돌, 사람 눕힘, 던지기/페이드, 60초 종료/입력 차단, 재시작, 실제 Addressables 콘텐츠 로드.

이 기록은 계획이며 구현/검증 완료를 의미하지 않는다.
