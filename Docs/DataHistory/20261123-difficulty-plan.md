# 벙커 난이도 적용 계획

Assets, ProjectSettings, Docs의 난이도 선택, 틱 길이, 사건 및 습격 주기와 데이터 목록의 예약 항목을 확인했다. 해당 시간을 소유하는 정본은 `data.bunker.rules` 하나다. 타이틀과 튜토리얼은 기존 FarmingRunTransfer에 회차의 선택만 전달한다.

기존 어려움 값(960틱, 0.33초, 사건 40틱, 첫 습격 20틱, 이후 80틱)을 기준으로 쉬움과 중간의 초/틱과 총 틱 분할 수를 같은 SO에 추가한다. 재시도 시 선택을 보존하고 새 타이틀에서는 어려움을 기본 선택한다. 세 난이도의 시계, 발표와 종료, 공유 에셋 보존을 검증한다.
