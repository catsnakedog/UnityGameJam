# WebGL 파밍 규칙 로드

브라우저에서 튜토리얼 방송을 마친 뒤 파밍 씬이 ‘파밍 데이터를 불러오고 있습니다’에서 멈추는 현상을 재현했다. 게임 DB와 파밍 Addressables 번들 요청은 모두 HTTP 200으로 완료됐다.

`FarmingDataLoader`가 규칙 핸들의 `Completed` 콜백으로 대기를 끝내도록 수정했다. 실패한 로드는 원래 예외를 전달하고, 파밍 씬이 닫히면 구독과 핸들을 해제한다.

`data.farming.rules`의 정본은 `Assets/Settings/Farming/FarmingRules.asset`이다. 기존 목록과 파밍 씬·튜토리얼의 소비 코드를 대조해 같은 주소 `data/farming/rules`를 재사용했다.

Unity 6000.3.28f1 WebGL 릴리스 빌드를 로컬 HTTP로 실행했다. 브라우저에서 튜토리얼 방송 일곱 줄을 진행한 뒤 파밍 준비·구조 카운트다운과 결과 화면을 확인했다. ‘벙커로 이동’을 누르자 벙커 도착 방송이 재생됐고, 다음 대사에서 팀원이 있는 거실이 강조됐다. 빌드 결과는 오류 0건·경고 348건이며, 배포 ZIP의 25개 파일은 CRC 검사를 통과했다.
