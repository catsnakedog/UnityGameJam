# 음식과 장비 적용 전 조사

2026-11-18 KST · UnityGameJam · Codex. DataRegistry의 active/planned와 Assets, ProjectSettings, Docs의 food, water, choco, hunger, equipment, 장착, 허기를 조사했다. food는 이미 파밍 무게 1칸을 소유하며 기존 맵에 배치된다. 스파게티 통조림으로 구체화하고 같은 식품의 ID를 추가하지 않는다. 허기·회분의 편집 정본은 발견되지 않아 기존 벙커 틱 SO를 확장한다. 캐릭터 능력 시트에는 현재값을 추가하지 않는다.

가방은 파밍 투입 스냅샷과 이벤트 수량을 조회했고 장비 카드는 읽기 인터페이스만 있었다. 벙커 가방에서 각 파밍 물자의 개별 수명과 장착 소유권을 관리하고 이벤트 물자는 기존 수량 API에서 소비한다. 검증 예정 범위는 실제 틱, 별도 통조림, 멘탈 회복, 드래그 대상 선택, 교체·해제 및 재시작이다.
