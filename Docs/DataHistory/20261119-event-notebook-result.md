# 이벤트 선택 결과 표시

기존 data.events의 yesResult와 noResult를 EventCatalog에서 읽어 EventLaptopPopup 본문에 전달한다. 실제 적용 효과는 EventEffectExecutor의 요약을 사용한다. 데이터 목록과 기존 Events 명세를 확인했으며 CSV, 시트, 별도 테이블을 추가하지 않았다. [정본과 명세](../DataSpecs/Events.md)

Unity Play에서 ev_door의 양쪽 선택 모두 해당 결과 문장이 본문에 나타나고 실제 수치 요약은 하단에 표시되는 것을 확인했다. [결과 화면](../Images/BunkerEventChoice.png)
