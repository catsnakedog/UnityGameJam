# 복도 방향 수정

- 사용자 정정: 복도는 왼쪽 아래에서 오른쪽으로 올라가고 호실은 복도의 왼쪽 위에 배치한다.
- 논리 배치 좌표의 투영을 `x=(u+v)/2, y=(v-u)/4`로 변경한다. Floor/Wall/Ceiling 타일은 (v,-u-1) 셀로 변환하고, 개체·문·Collider2D·벙커·시작 위치도 같은 투영을 사용한다. 2:1 타일 규격은 바꾸지 않는다.
- 사용 데이터 ID: data.farming.pickups, data.farming.rules. 정본 CSV/SO, 필드, 수치, 주소, 로더 변경 없음. 씬이 배치의 정본이며 새 데이터 정본 없음.
- 이전 방향의 실 플레이 검사 63개는 통과했으나, 변경된 배치에서 출입·충돌·시야·파밍 회귀 검증을 다시 수행한다. 최종 기록은 후속 검증 이력으로 남긴다.
