# 기획 선행 조건 확정

- 사용자 답변: 본문 기준 **기획 50% 초과**부터 아트·프로그래밍 개발 가능.
- data.bunker.rules의 기존 BunkerRules.asset에 planningUnlockPercent(float, 퍼센트포인트, 유한 0 이상 100 미만, 기본값 없음)를 추가한다. 값 50은 SO만 편집 정본이며 스크립트/씬에 독립적인 밸런스를 복제하지 않는다.
- BunkerSimulation.ProcessWork는 틱 시작 시 기획 진행률을 기준으로 아트/프로그래밍 능력 합산을 허용한다. 50%에서는 잠금, 50% 초과 시 허용한다. 기획 작업과 방 이동/통과는 유지한다. 이벤트의 명시적 PROGRESS 효과는 기존대로 별도 적용한다.
- 기존 주소/GUID/캐시/수명 유지. 시간표·평가 미연결 항목은 별도이며 임시 총 틱/간격을 이번 조건 변경에 끼워 넣지 않는다.
- 검증: 이하 후속 이력에서 실제 경계값/이동 및 콘텐츠 빌드 결과를 기록한다. 노션 공간 문서의 100% 문구를 사용자 확정 기준으로 정정한다.
