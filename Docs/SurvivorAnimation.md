# 벙커 생존자 애니메이션

[공유 Drive의 player 폴더](https://drive.google.com/drive/folders/1IfsNUxatQhkW-Fn5cK1Jo6TcwFAyZ5SC)에 캐릭터별 원본을 보관한다. Unity에 반영할 때는 바뀐 파일을 같은 이름으로 `Assets/Art/Shelter/Characters/no01_tags`~`no06_tags`에 복사한다. Unity가 임포트를 마치면 편집 모드에서 **Tools → Shelter → Refresh Survivor Animations**를 실행한다. 메뉴는 공용 Survivor 프리팹의 클립 참조를 갱신한다. Drive 업로드와 Unity 반입은 별도 단계다.

| 파일명 (.aseprite) | 재생 조건 |
| --- | --- |
| idle_1 / idle_2 | 일반 / 피곤한 대기, 반복 |
| no01_tags/idle_1rim | 1번 캐릭터 대기 포즈의 검정 실루엣·빨강 테두리 마스크. 별도 10프레임 클립으로 보관하며 기본 대기는 idle_1을 재생한다. |
| walk_1 / walk_2 | 실제 수평 이동 중 일반 / 피곤한 걷기, 반복 |
| workin (구 파일명 sit) | 벙커에서 이미 작업 가능한 자기 부서의 지정 자리에 새로 도착하면 한 번 재생한 뒤 working으로 전환한다. 방에서 대기 중에 작업이 열리면 지정 자리에서 바로 working을 반복한다. |
| working (구 파일명 typing) | 지정 자리에서 작업하는 동안 반복한다. 다른 부서 방에서는 대기 동작으로 작업한다. |
| sleep | 수면 방에 도착해 머무는 동안 반복 |
| dead_2 | 멘탈이 0이 되면 현재 프레임을 0.16초 동안 페이드아웃하고 창백한 얼굴의 누운 자세를 0.16초 동안 페이드인한다. 각성 전까지 유지한다. |
| dead_1 | 파밍에서 플레이어가 사람을 들고 있을 때 정상 얼굴색의 누운 원화를 손에 맞춘다. 바닥에 내려놓으면 대기 자세로 돌아온다. |
| attack | 문 앞 보초 공격과 실내 근접 공격에서 한 번 재생 |
| hit | 실내 교전에서 실제 피해를 입은 생존자가 한 번 재생한다. 멘탈이 0이 되면 탈진 전환이 우선한다. |
| no01~no06 | 해당 캐릭터의 기본 정지 그림. 없으면 idle_1의 첫 프레임 사용 |

파일 하나에 한 동작을 넣는다. 현재 원본은 128×128 캔버스에서 가로 중앙, 위에서 96픽셀 지점에 발을 맞춘다. 같은 기준으로 그리면 동작 전환 시 발 위치를 맞출 수 있다. Unity는 보이는 레이어를 프레임별로 합치고 Aseprite에서 정한 프레임 시간을 사용한다.

여섯 생존자 모두 일반·피곤 대기 각 10프레임, 일반·피곤 걷기 각 6프레임을 사용한다. 피곤 기준은 [BunkerRules](DataSpecs/BunkerRules.md)의 멘탈 50 이하이며 기절 상태가 우선한다. 파밍에서는 시작 화면에서 고른 생존자를 조작한다. 씬을 직접 실행하면 `FarmingRules.startingPersonId`를 사용한다. 파밍에서 의자에 앉는 원화가 있는 3·4·5·6번은 책상 앞에서 `working`을 반복한다. 1·2번과 운반 후 내려놓은 인물은 `idle_1`로 대기한다. 의자 사용 여부는 Survivor 프리팹의 인물별 Working Uses Chair에서 설정한다. 작업·수면 등 아직 원화가 없는 동작은 기존 대기 그림을 표시한다.

2026-11-19 공유 원본 대조에서 2~4번 대기 6개를 갱신하고 5·6번 원본 8개를 추가했다. Unity 6000.3.28f1에서 24개 클립의 프레임 시간과 샘플링 결과 192개를 원본과 대조하고 파밍 인물 프리팹 6개의 연결을 확인했다. [실제 4~6번 배치 화면](GameDev/Preview-clock-events.png)

같은 날 재확인한 Drive 원본은 일반 동작 24개, 정지 그림 5개, 테두리 마스크 1개다. 마스크 반영 후 30개 모두 프로젝트 파일과 바이트 단위로 일치했다. Unity에서 생존자 6명의 동작 참조와 마스크를 포함한 25개 클립의 프레임 202개를 원본 재생 시간에 맞춰 확인했다.
