# 엘리베이터 자동 이동

캐릭터를 클릭한 뒤 목적지 방을 클릭하면 자동으로 이동한다. 엘리베이터는 먼저 호출한 사람이나 좀비의 층으로 간다. 탑승할 때 같은 층 승강장에 다른 호출자가 있으면 대기 순서대로 한 명 더 타고, 혼자면 바로 출발한다. 같은 층에서 샤프트 앞을 지나가는 캐릭터는 그대로 걸어간다.

동승자의 목적층이 첫 호출자의 경로 중간이면 먼저 내려준다. 그 밖에는 첫 호출자의 목적층을 먼저 방문한다. 탑승자가 모두 내리면 남은 호출 중 가장 오래된 호출을 처리한다. 탑승 중 다른 방을 클릭하거나 정지를 명령하면 해당 인물이 하차한 뒤 적용한다. 전투·탈진·취소로 대기자가 움직일 수 없으면 다음 사람에게 넘긴다. 차량 위에 현재 이용자와 대기 인원을 표시한다.

두 명이 타면 차 안에 나란히 선다. 이벤트 팝업 중에는 차량과 탑승자가 같이 멈춘다. 좀비도 두 마리까지 동승하며 각자의 HP와 상태를 유지한다. 좀비는 승강장에 빈자리가 생기면 내려서 지상 이동과 접촉·점거 전투를 이어간다. 같은 층으로 가는 좀비는 호출 지점에서 기다리는 줄을 통과할 수 있다.

## 자유 배치

현재 `Assets/Scenes/ShelterPrototype.unity`를 편집한다. Farming에서 구조한 캐릭터만 생성되며 벙커 씬을 직접 실행하면 명단이 비어 있다.

| 추가할 것 | 메뉴 / 프리팹 | 배치 방법 |
|---|---|---|
| 방 | GameObject > Shelter > Room | Transform은 바닥 중앙. Width/Height 조정 |
| 통로·승강장 | GameObject > Shelter > Corridor | 같은 층 방과 좌우 끝을 맞닿게 배치 |
| 엘리베이터 | GameObject > Shelter > Elevator / Assets/Prefabs/Shelter/Elevator.prefab | Transform은 샤프트 하단. Height로 연결할 층 범위 지정. Initial Stop은 아래부터 0 기반 시작층 |

엘리베이터 X가 방/통로 폭 안에 있고 바닥이 샤프트 높이 범위 안에 있으면 정차층을 자동 인식한다. 중간 층도 자동 연결한다. 호출 지점은 샤프트 좌우 `boardingOffset`, 하차 지점은 반대편 `exitOffset`이므로 해당 지점을 덮는 바닥을 배치한다. 현재 규칙에서는 중심에서 좌우 2.4 이상 바닥을 확보하면 양쪽에서 이용할 수 있다. 대기열이 길어질 수 있는 곳은 통로를 더 넓힌다. 수동 연결 참조나 Bake는 필요 없다.

회전은 0도, 크기는 Width/Height나 양수 Scale로 편집한다. 연결 허용 오차는 기존 ShelterNavigation.connectionTolerance다. 경로는 걷기 시간과 차량 이동 시간으로 선택하며 대기열 길이를 보고 경로를 계속 바꾸지는 않는다. 배치·접근 가능 여부는 0.2초마다 갱신하지만 차의 현재 층이나 소유자 변화는 경로 재계산을 유발하지 않는다.

Accessible을 끄거나 엘리베이터를 비활성화하면 연결이 끊어진다. 탑승자가 있으면 남아 있는 정차층 중 가까운 층에 내려놓고 운행을 취소한다. 연결을 복구하면 새 이동 명령과 좀비 경로 탐색에 자동 반영한다. 기존 사다리 객체/프리팹은 비활성·호환용으로 보존했으며 활성 경로에서 사용하지 않는다.

## 데이터와 검증

공용 수치는 [ElevatorRules.asset](../Assets/Settings/Shelter/ElevatorRules.asset) 하나에서 편집한다. 데이터 ID `data.shelter.elevators`, [명세](DataSpecs/ElevatorRules.md). 수정 후 기존 Addressables 콘텐츠 빌드 또는 Tools > Shelter > Build Elevator Data를 실행한다. 씬에는 ShelterTransit이 기존 시뮬레이션/명단/입력 관리자와 연결되어 있다. 새 빈 씬은 이 관리자 구성이 필요하므로 현재 씬을 복제해서 배치하는 방법을 권장한다.

[Edit 검증](Elevators-checks-edit.txt), [Play 검증](Elevators-checks-play.txt), [기존 좀비 전투 회귀 검증](Zombies/Verification-play.txt). 동승, 목적층별 하차, 세 번째 호출자의 순서, 같은 층 통과와 일시정지를 검사한다. [동승 변경 이력](DataHistory/20261118-shelter-elevator-pairs.md).

## 기절한 생존자 구조

움직일 수 있는 생존자를 선택하고 기절한 생존자를 클릭하면 구조자가 해당 위치로 이동한다. 도착하면 대상자를 들고 수면실까지 자동 이동한다. 층이 다르면 기존 엘리베이터를 이용한다. 구조 명령 중에는 다른 생존자를 조작할 수 있다. 구조자가 다시 기절하면 탑승 중인 차량에서 하차하거나 현재 바닥에 환자를 내려놓고 다른 생존자가 구조를 이어간다. 수면실 인계 후 기절자는 매 틱 회복하고 기준 멘탈에 도달하면 다시 이동·작업·전투할 수 있다. [방 멘탈 설정](DataSpecs/BunkerRules.md)
