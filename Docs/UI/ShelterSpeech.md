# 벙커 말풍선

말풍선은 머리 왼쪽 위에 뜨고 오른쪽 아래의 짧은 꼬리가 발화자를 가리킨다. 현재 머리 그림을 따라가며 이름표나 게이지와 겹치면 왼쪽이나 아래로 비켜난다. 머리 오른쪽 위는 감정 표시가 사용한다. 말풍선은 카메라 입력과 캐릭터 클릭을 통과시킨다.

말풍선 테두리와 꼬리는 `Assets/Art/UI/ShelterSpeech.png`에서 수정할 수 있다. 투명 배경에 먹색(`#292C30`)과 상아색(`#F2F1E9`)을 사용한다. `ShelterSpeech.prefab`에서 글꼴과 여백을 조정하고, 생존자·좀비 프리팹의 `Shelter Speech Anchor → Gap`에서 머리와 꼬리 사이의 기본 간격을 조정한다. 짧은 대사는 한 줄에 맞추고 긴 대사는 자동으로 줄을 바꾼다.

생존자와 좀비가 같은 프리팹을 사용한다. 말풍선은 이동하는 발화자를 따라가며, 사라진 좀비의 마지막 대사는 마지막 위치에서 표시한다. 같은 발화자의 전투 대사는 순차 표시하고 반복되는 일상 대사는 자리를 비운 뒤에만 표시한다.

## 생존자 감정 표시

빡침은 근접전에서 피해를 받은 생존자의 머리 오른쪽에 붉은 힘줄로 표시한다. 우울은 기존 피곤 상태에 진입할 때 먹구름과 빗방울로 표시한다. 같은 피격으로 멘탈이 피곤 구간에 들어가면 먹구름이 이어받고, 탈진하거나 새 회차를 시작하면 표시를 지운다.

두 PNG는 `Assets/Art/UI/Emotions/anger.png`와 `gloom.png`에 있다. 크기는 16×16 px, 필터는 Point, 배율은 생존자와 같은 22 PPU다. 투명 배경에 각 두 색만 쓴다. 공통 외곽은 `#342D3D`, 빡침은 빨강 `#ED715E`, 우울은 파랑 `#91A9CF`이다.

표시는 매 프레임 캐릭터 그림의 오른쪽 위를 따라간다. 기본 위치에서 아이콘의 왼쪽 변은 캐릭터 오른쪽 끝에서 1픽셀 떨어지고, 중심은 머리 꼭대기보다 3픽셀 높다. 멘탈 게이지와 겹칠 높이에서는 오른쪽으로 조금 더 띄운다. `Survivor.prefab → SurvivorEmotion → Corner Offset Pixels`에서 아이콘 왼쪽 아래의 상대 위치를, `Duration`에서 표시 시간(기본 1.35초)을 조정한다. 힘줄은 좌우 한 픽셀씩 떨리고, 먹구름은 두 픽셀 내려온다. 그림 교체 시 같은 경로의 PNG를 덮어쓰고 기존 `.meta`를 유지한다.
