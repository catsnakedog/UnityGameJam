# 벙커 말풍선

말풍선은 캐릭터 오른쪽에 뜨고 왼쪽 아래의 짧은 꼬리가 발화자를 가리킨다. 꼬리는 발 위치에서 오른쪽으로 0.55, 위로 1.8 월드 유닛에 고정된다. 캐릭터가 움직이면 함께 이동하고, 자세와 바라보는 방향이 바뀌거나 대사가 여러 줄이 되어도 발과 꼬리 사이의 거리는 일정하다. 말풍선은 카메라 입력과 캐릭터 클릭을 통과시킨다.

말풍선 테두리와 꼬리는 `Assets/Art/UI/ShelterSpeech.png`에서 수정할 수 있다. 투명 배경에 먹색(`#292C30`)과 상아색(`#F2F1E9`)을 사용한다. `ShelterSpeech.prefab`에서 글꼴과 여백을 조정하고, 생존자·좀비 프리팹의 `Shelter Speech Anchor → Offset`에서 꼬리의 가로·세로 위치를 조정한다. 짧은 대사는 한 줄에 맞추고 긴 대사는 자동으로 줄을 바꾼다.

생존자와 좀비가 같은 프리팹을 사용한다. 말풍선은 이동하는 발화자를 따라가며, 사라진 좀비의 마지막 대사는 마지막 위치에서 표시한다. 같은 발화자의 전투 대사는 순차 표시하고 반복되는 일상 대사는 자리를 비운 뒤에만 표시한다.

생존자가 탈진하면 그 인물의 현재 대사와 대기 중인 대사를 즉시 지우고 직군별 탈진 대사를 한 번 표시한다. 이후에는 구조되어 수면실에서 깨어날 때까지 전투와 일상 대사를 받지 않는다. 탈진 중 멘탈이 일부 회복돼도 같은 규칙을 적용한다.

## 생존자 감정 표시

같은 캐릭터가 같은 행동으로 같은 감정을 다시 표시하려면 게임 시간으로 10초가 지나야 한다. 반복 작업 틱은 표시 시간을 연장하지 않는다. 작업 중 아이템을 쓰거나 전투에 참여하면 해당 행동의 감정은 따로 표시된다. 간격은 공용 Survivor 프리팹의 SurvivorEmotion → Repeat Cooldown에서 조정한다.

멘탈이 실제로 하락하면 파란 먹구름(슬픔), 상승하면 노란 반짝임(기쁨)이 뜬다. 음식 섭취나 장비 장착에 성공해도 기쁨이 뜬다. 전투에 참여하거나 근접·원거리 공격을 판정하면 해당 생존자에게 붉은 힘줄(화남)이 뜬다. 같은 공격으로 피해를 받으면 화남을 표시하고, 처치 보상으로 멘탈이 오르면 기쁨으로 전환한다. 탈진과 회차 초기화는 기존 표시를 지운다.

세 PNG는 `Assets/Art/UI/Emotions`에 있다. 크기는 16×16 px, 필터는 Point, 배율은 22 PPU다. 투명 배경에 공통 외곽색 `#342D3D`와 감정별 색 한 가지를 사용한다. 화남은 `anger.png`의 빨강, 슬픔은 `gloom.png`의 파랑, 기쁨은 `joy.png`의 노랑이다.

표시는 머리 오른쪽 위에 살짝 겹친다. 아이콘 중심은 캐릭터 중심선에서 오른쪽으로 3픽셀, 현재 그림 꼭대기에서 아래로 1픽셀에 놓인다. 멘탈 게이지에 닿으면 아이콘을 아래로 옮겨 한 픽셀의 여백을 둔다. `Survivor.prefab → SurvivorEmotion → Head Offset Pixels`에서 위치를, `Duration`에서 표시 시간(기본 1.35초)을 조정한다. 힘줄은 좌우 한 픽셀씩 떨리고, 먹구름은 두 픽셀 내려오고 반짝임은 두 픽셀 올라온다. 그림 교체 시 같은 경로의 PNG를 덮어쓰고 기존 `.meta`를 유지한다.
