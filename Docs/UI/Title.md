# 죽어도 개발 시작 화면

`Assets/Scenes/Title.unity`는 빌드의 첫 씬이다. 1280×720 기준의 화면 중앙 위에 제목을 배치하고 그 아래에 게임 시작, 옵션, 게임 종료 버튼을 세로로 배치한다. Neo둥근모 글꼴과 프로젝트의 파밍 버튼 스프라이트를 사용한다. 배경 그림은 `Assets/Art/UI/Title/bunker_dusk.png`에서 교체한다.

게임 시작을 누르면 왼쪽에 선택 인물의 idle 애니메이션과 여섯 이름 버튼이 나타난다. 오른쪽은 벙커의 ShelterCharacterCard 프리팹으로 같은 인물의 초기 정보와 초상화를 표시한다. 뒤로 가면 시작 화면으로 돌아가며, 선택 완료 시 해당 인물로 바로 파밍 준비가 시작된다.

제목 화면의 옵션 버튼, 캐릭터 선택 및 플레이 화면의 우측 상단 옵션 탭, Esc 키가 같은 옵션 창을 연다. 다섯 음량 슬라이더와 음소거는 기존 SoundManager에 연결한다. 창을 닫으면 열기 전 시간 배율과 입력 포커스로 돌아간다. 옵션 프리팹은 `Assets/Prefabs/UI/Resources/GameOptions.prefab`이다.
