# 죽어도 개발 시작 화면

타이틀 배경의 여섯 장소에는 각각 두 명의 캐릭터가 등장한다. 파밍 방에서는 책상 작업과 대기, 복도에서는 왕복 걷기와 대기, 기획실에서는 독서와 칠판 쓰기, 아트실과 프로그래밍실에서는 책상 작업, 거실에서는 독서와 지친 대기 모션을 사용한다. `Main menu → Location slideshow → Performers`에서 장소, 모션, 방향, 발 위치를 편집한다. 발 위치는 배경 이미지 왼쪽 아래 기준 픽셀이며 걸음 거리는 오른쪽이 양수다. 인물은 해당 장소와 함께 이동하고 전환된다.

`Assets/Scenes/Title.unity`는 빌드의 첫 씬이다. 1280×720 기준의 화면 중앙 위에 제목을 배치하고 그 아래에 게임 시작, 옵션, 게임 종료 버튼을 세로로 배치한다. Neo둥근모 글꼴과 프로젝트의 파밍 버튼 스프라이트를 사용한다. 메인 메뉴 뒤에서 파밍 방, 기획실, 파밍 복도, 아트실, 프로그래밍실, 거실이 차례로 반복된다. 도트 비율을 유지한 채 천천히 좌우로 이동하고, 8초마다 마지막 1.6초 동안 다음 장소와 겹쳐 전환한다. 순서와 시간은 Title 씬의 Main menu → Location slideshow에서 편집한다. 인물 선택의 배경 그림은 `Assets/Art/UI/Title/bunker_dusk.png`다.

메인 메뉴의 로고는 `Assets/Art/UI/Title/title.png`를 사용한다. 투명 PNG 원본(1536×1024)을 단일 스프라이트로 가져오며, `Main menu → Title`의 Image에서 원본 비율을 유지한다. 1280×720 기준 배치 영역은 420×280이고 화면 높이에 맞춰 조절된다. 로고를 교체할 때는 기존 메타 파일을 유지하고 PNG를 덮어쓴다.

게임 시작을 누르면 왼쪽에 선택 인물의 idle 애니메이션과 여섯 이름 버튼이 나타난다. 오른쪽은 벙커의 ShelterCharacterCard 프리팹으로 같은 인물의 초기 정보와 초상화를 표시한다. 뒤로 가면 시작 화면으로 돌아가며, 선택 완료 시 해당 인물로 바로 파밍 준비가 시작된다.

인물 카드 아래의 난이도 버튼에서 쉬움·중간·어려움을 고른다. 현재 선택은 황금색이고 기본 선택은 어려움이다. 선택 완료 시 인물과 난이도를 함께 확정한다. 튜토리얼의 마지막 방송을 클릭하면 보통(Medium)으로 시작하고 엔딩에서 다시 하기를 누르면 직전 회차의 난이도로 시작한다. [난이도별 일정](../DataSpecs/BunkerRules.md)

제목 화면의 옵션 버튼, 캐릭터 선택 및 플레이 화면의 우측 상단 옵션 탭, Esc 키가 같은 옵션 창을 연다. 다섯 음량 슬라이더는 기존 SoundManager에 연결한다. ‘메인으로’는 현재 플레이를 종료하고 타이틀 화면으로 돌아간다. ‘닫기’는 열기 전 시간 배율과 입력 포커스를 복구한다. 옵션 프리팹은 `Assets/Prefabs/UI/Resources/GameOptions.prefab`이다.
