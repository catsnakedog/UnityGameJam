# 벙커 작업 완료 표시

작업 분야에 진척을 더한 생존자의 이름 위에 분야 아이콘과 개인 증가량을 한 줄로 띄운다. 아이콘과 증가량을 합친 줄의 중앙을 캐릭터 머리에 맞추며, 숫자 길이가 달라지면 정렬을 다시 계산한다. 기획은 전구, 그래픽은 팔레트, 프로그래밍은 기존 장비 아이콘인 노트북을 쓴다. 아이콘 오른쪽의 `+0.6%`는 이번 틱에 해당 분야 진행률이 0.6%p 늘었다는 뜻이다.

- `Survivor.prefab > Work feedback`은 중심 높이 2.86 월드 단위에서 0.28만큼 떠오른다. 표시 시간은 0.85초이며 마지막 3분의 1 동안 사라진다. 프리팹 루트의 `WorkProgressFeedback`에서 이동 거리와 시간을 편집할 수 있다.
- 입력을 받지 않는 월드 캔버스다. 각 생존자에 저장된 표시 한 개를 다음 작업에 재사용한다. 재시작과 비활성화 시 숨긴다.
- 같은 방의 증가량은 분야별 작업 적용 직후의 실제 증가량을 개인 유효 능력에 비례해 나눈다. 100%까지 남은 진척이 적으면 개인 표시도 비례해 줄어든다. 장비 보정을 포함하며 소수 셋째 자리까지 반올림한다. 반올림하면 0이 되는 양수는 `<0.001%`로 표시한다.
- 이동·탈진·잠긴 분야·작업 능력 0 등으로 해당 인물의 기여가 없으면 새 표시가 뜨지 않는다. 기존 진행도와 작업 멘탈·주기는 [벙커 규칙](../DataSpecs/BunkerRules.md)과 [캐릭터 명세](../DataSpecs/Characters.md)를 따른다.
- `Assets/Art/UI/WorkPlanning.png`, `WorkGraphics.png`는 40×40 투명 PNG다. 프로그래밍은 기존 `Assets/Art/UI/Inventory/laptop.png`를 참조한다. 그림만 교체할 때는 경로·크기·Single Sprite 설정과 기존 .meta를 유지한다.
- `WorkProgressFeedbackSetup.Apply()`로 생존자 프리팹에 표시를 설치하고 `Validate()`로 저장된 구성과 참조를 검사한다. Play에서는 기획방에 2명을 놓고 기획을 100% 직전으로 설정한 뒤, 같은 틱 두 표시가 상한까지 남은 값에 비례하는지 확인할 수 있다.
