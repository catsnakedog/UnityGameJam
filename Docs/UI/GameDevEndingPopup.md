# 엔딩 컷씬과 결과창

벙커의 기획·그래픽·프로그래밍이 모두 100%에 이르면 화면 중앙에 **게임 개발 완료**, 마지막 생존자가 탈진하면 **전원 탈진**을 표시한다. 두 조건이 한꺼번에 충족되면 완성을 표시한다. 종료 즉시 시계와 벙커 입력을 잠그고 1920×1080 기준 검은 페이드 중앙에 흰색 72포인트 글자를 1.5초 유지한 뒤 엔딩 컷씬으로 이동한다. 시간 만료는 기존 페이드로 바로 이어진다.

개발 종료 점수가 결정되면 벙커 입력과 시계를 잠그고 화면을 검게 페이드한다. Ending 씬은 벙커 전투실과 외부 통로를 실제 입구 문 기준으로 배치한다. 네 종류의 좀비 열두 마리가 같은 바닥 높이에서 이동하며, 문 앞을 지나는 좀비가 걸으면서 말한다.

| 판정 ID | 연출 |
|---|---|
| ending_unfinished | 좀비들이 전투실에서 왼쪽 출구로 빠져나가며 차례로 불평한다. |
| ending_released | 좀비들이 외부 통로에서 오른쪽 전투실로 들어오며 침입 대사를 한다. |
| ending_breakthrough | 좀비들이 만족 대사를 하며 전투실에서 왼쪽 출구로 걸어 나간다. 마지막 좀비가 떠나면 파밍 방으로 전환하고 개발자들이 idle 자세로 뛰며 기쁨을 표현한다. |

세 분기 모두 마지막 장면 뒤 같은 종이 정산지을 연다. 해상도 기준은 1920×1080이며 기존 16:9 뷰포트와 네오둥근모를 사용한다. 제목과 설명, 소수 세 자리 평가 점수는 GameDevManager의 판정 결과를 표시한다. 세 자리 반올림이 실제 엔딩 경계를 넘는 경우 점수 뒤에 ‘미만’ 또는 ‘초과’를 표시한다. 세 분야를 모두 완성하면 1.000으로, 만점 직전의 점수가 1.000으로 반올림되면 ‘1.000 미만’으로 표시한다. 정산지 하단의 ‘메인으로 가기’는 타이틀로, ‘다시 하기’는 해당 회차의 시작 기획자로 파밍 첫 장면에 진입한다. 옵션을 열면 컷씬도 멈춘다.

## 에디터에서 엔딩 테스트

`Tools → GameDev → 엔딩 테스트`에서 **배드**, **노멀**, **굿** 중 하나를 누르면 플레이 모드가 시작된다. `Ending.unity`를 직접 열고 Play를 눌러도 이 창이 열린다. 테스트는 새 벙커를 불러오고 선택한 엔딩의 카탈로그 기준 점수를 제출한다. 이후의 페이드, 음악, 대사, 결과창과 두 버튼은 실제 게임 경로를 따른다.

컷씬을 보거나 결과창이 열린 상태에서 테스트 창의 버튼을 다시 누르면 같은 엔딩을 처음부터 재생하거나 다른 엔딩으로 전환할 수 있다. 테스트를 마치면 Unity의 Stop을 누른다.
