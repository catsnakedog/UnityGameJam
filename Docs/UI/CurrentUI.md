# 죽어도 개발 · 화면별 UI 목록

2026-11-19 현재 프로젝트의 Unity 플레이 화면이다. 패널과 말풍선은 글자가 보이도록 일부를 발췌했고, 아이콘 표는 현재 연결된 스프라이트를 확대했다. 나란히 놓인 이미지는 클릭하면 크게 볼 수 있다.

| 오른쪽 | 인물 정보 카드 | 이름·직군·초상, 멘탈 수치와 바, 능력 4종, 허기 10칸, 장착 칸을 표시한다. 선택 화면에서는 닫기 버튼을 숨긴다. |
| 하단 | 이동 버튼 | 왼쪽 `뒤로`, 오른쪽 `선택 완료 · 게임 시작` |

## 공용 옵션

![옵션 창에 배치된 음량 슬라이더 5개와 메인으로·닫기 버튼](../Images/CurrentUI/Options.png)

| 위치 | UI 요소 | 표시 내용과 상태 |
|---|---|---|
| 메인 메뉴 또는 화면 우상단 | 옵션 버튼 | 메인 메뉴에서는 메뉴 버튼, 캐릭터 선택·파밍·벙커·엔딩에서는 `옵션` 탭으로 표시한다. |
| 화면 중앙 | 종이 옵션 패널 | `전체 음량`, `배경 음악`, `효과음`, `인터페이스`, `환경음` 슬라이더 5개. 각 슬라이더에는 트랙, 채움, 손잡이가 있다. |
| 창 하단 | 메인으로·닫기 | `메인으로`를 누르면 현재 플레이를 종료하고 타이틀로 돌아간다. `닫기`는 현재 화면을 다시 연다. |

| 중앙 안내 패널 | 로딩·시작·오류 | 로딩 시 `준비 중`, 시작 안내에는 제목·설명과 `E 준비 시작` 버튼, 오류 시 `데이터를 확인해 주세요`와 오류 문구를 표시한다. 시작 안내는 파밍 화면을 직접 열었을 때 보인다. |
| 중앙 결과 패널 | 파밍 종료 | `파밍 종료` 제목 아래 확보한 생존자·물자, 남겨진 사람 수를 표시한다. 하단 버튼은 `벙커로 이동`이다. |

## 벙커 HUD

[![왼쪽 시계와 캐릭터 카드, 상단 진행도, 오른쪽 가방과 소방 도끼 툴팁이 함께 열린 벙커 화면](../Images/CurrentUI/Shelter.png)](../Images/CurrentUI/Shelter.png)

| 위치 | UI 요소 | 표시 내용과 상태 |
|---|---|---|
| 좌상단 | 시계·일정 표식 | 원형 다이얼, 시계 방향으로 차는 링, 중앙 시각. 붉은 경고 표식은 `좀비 습격`, 청록색 마름모는 `중간 발표`이며 오른쪽에 범례가 있다. 지난 일정의 표식은 사라진다. |
| 상단 중앙 | 개발 진행도 | `기획`, `프로그래밍`, `그래픽` 카드마다 퍼센트와 가로 게이지가 있다. 잠긴 분야에는 자물쇠가 보이고, 마우스를 올리면 해금 조건 툴팁이 뜬다. |
| 진행도 아래 | 상태 문구 | 개발 준비, 결과 집계, 오류 또는 최종 결과를 표시한다. 개발 중에는 숨긴다. |
| 시계 아래 왼쪽 | 캐릭터 카드 | 선택한 인물의 이름·직군, 초상, 멘탈 수치·게이지, 기획·프로그래밍·아트·전투 수치, 허기 10칸을 표시한다. 우상단에 × 닫기 버튼이 있다. |
| 캐릭터 카드 하단 | 장착 칸 | `장착 아이템 · 1칸`. 비어 있으면 `장착한 아이템이 없습니다.`, 장착 중이면 아이콘과 이름이 보인다. |
| 우하단 | 가방 버튼·패널 | 가방 버튼 위로 `벙커 가방`이 열린다. 총 보유 개수와 아이콘·이름을 2열×2행으로 표시한다. 하단 종이 띠는 빈 가방이나 사용 불가 상태에서만 나타난다. 4개를 넘으면 ▲·▼와 스크롤 위치가 보인다. |
| 가방 슬롯 주변 | 툴팁·드래그 표시 | 마우스를 올리면 슬롯 모서리가 강조되고 왼쪽에 이름·효과·수량 또는 남은 사용 횟수가 뜬다. 드래그 중에는 아이콘이 포인터를 따라간다. 사용 불가 문구는 가방 하단에 표시한다. |

### 벙커 공간 안에 표시되는 UI

![거실 이름·인원, 선택된 생존자의 이름표·멘탈 바·감정 표시와 말풍선](../Images/CurrentUI/World.png)

![생존자 위에 표시되는 감정 아이콘 세 가지와 기획·그래픽·프로그래밍 작업 아이콘](../Images/CurrentUI/WorldIcons.png)

| 위치 | UI 요소 | 표시 내용과 상태 |
|---|---|---|
| 방 위·바닥 | 방 이름·인원·강조선 | 방 이름 옆에 사람 아이콘과 `{인원}명`. 점거되면 좀비 아이콘과 `x/x`로 바뀐다. 바닥 강조선은 목적지일 때 금색, 거절·점거 상태일 때 붉은색이다. |
| 생존자 주변 | 선택 마커·이름표·멘탈 바 | 선택한 인물에 마커가 뜬다. 머리 위에 이름과 멘탈 바가 보이고, 탈진하면 이름에 `· 탈진`이 붙는다. |
| 생존자 머리 위 | 작업·감정 표시 | 작업 기여량은 분야 아이콘과 `+{값}%`로 떠오른다. 화남은 빨간 얼굴, 슬픔은 파란 얼굴, 기쁨은 노란 얼굴로 표시한다. |
| 발화자 옆 | 말풍선 | 생존자와 좀비 모두 꼬리 달린 말풍선을 사용한다. 발화자를 따라가며 긴 문장은 줄바꿈한다. |
| 전투 대상 위 | 체력·피해 숫자 | 좀비는 이름, 현재 HP/초기 HP를 표시한다. 피해를 받은 대상 위에는 `-{값}`이 떠올랐다 사라진다. |
| 엘리베이터 위 | 이용 상태 | `호출 대기`, 이용자 이름, 대기 인원을 표시한다. |

## 사건 노트북과 중간 발표 정산지

사건은 노트북의 Command Prompt 창에 표시된다. 중간 발표는 클립보드에 세 분야의 진행률, 평가 점수, 멘탈 변화, 등급과 좀비 표정을 표시한다.

| 사건 선택 | 선택 결과 | 중간 발표 |
|---|---|---|
| [![사건 질문 아래 Yes와 No가 표시된 화면](../Images/CurrentUI/Event.png)](../Images/CurrentUI/Event.png) | [![선택 결과 문장, 변화량, 계속 버튼](../Images/CurrentUI/EventResult.png)](../Images/CurrentUI/EventResult.png) | [![발표 진행률, 평가 점수와 등급](../Images/CurrentUI/Presentation.png)](../Images/CurrentUI/Presentation.png) |

| 표시 상태 | 본문과 버튼 |
|---|---|
| 사건 본문 출력 | 사건 ID와 제목 아래 본문이 한 글자씩 나타난다. `전체 보기` 버튼으로 문장 전체를 펼친다. |
| 선택 대기 | 본문 전체와 `Yes`·`No` 버튼을 표시한다. |
| 선택 결과·오류 | 결과 문장과 변화량 요약, `계속` 버튼을 표시한다. 선택을 다시 할 수 있는 오류는 오류 문구와 선택 버튼을 함께 보여 준다. |
| 중간 발표 | `중간 발표` 제목, 세 분야 진행률, 평가 점수, 멘탈 증감, 색으로 구분한 등급을 표시한다. 하단에는 `계속` 버튼 하나가 보인다. |
