# 주최 측 튜토리얼

타이틀에서 튜토리얼을 고르면 복도 방송 → 파밍 → 결과 화면의 **벙커로 이동** → 벙커 방송 순서로 진행한다. 일반 게임 시작과 벙커 씬 직접 실행은 벙커 운영으로 바로 진입한다.

## 화면과 입력

두 씬이 `Assets/Prefabs/UI/TutorialBroadcast.prefab`을 공유한다. 1920×1080 기준 16:9 영역에서 우측 스피커, 꼬리가 스피커로 향하는 9슬라이스 말풍선, 한국어 TMP 본문, 하단 진행 문구, 대상 주변을 어둡게 하는 네 패널을 표시한다. 화면을 클릭하거나 탭하면 한 문장씩 진행한다. 옵션을 열면 방송 동작과 입력이 함께 멈춘다.

| 구간 | 안내와 강조 대상 |
|---|---|
| 복도 | 시작 위치에서 인사, 복도 전체에서 A/D 이동과 E 상호작용, 셔터에서 벙커 투입 안내 |
| 벙커에 도착 | 준비된 벙커의 기본 구도로 방송 시작 |
| 팀원과 개발 | 생활 공간에서 팀원 선택과 방 이동, 기획실·프로그래밍실·그래픽실을 차례로 비추며 배치와 진척 설명 |
| 수면과 방어 | 수면실에서 빈 텐트 선택 및 기절자 구조, 입구에서 보초 배치 및 교대 안내 |
| 가방·시계·이벤트 | 실제 가방을 열어 물자 사용을 안내하고 시계에서 발표와 습격 일정을 설명한 뒤 돌발 상황과 최종 제출 안내 |

벙커 방송은 시뮬레이션의 일시정지와 지휘 입력 잠금을 소유한다. 마지막 클릭으로 열린 가방을 닫고 입장 시점의 카메라 위치에서 운영을 시작한다. 파밍을 재시도해도 같은 튜토리얼 회차가 이어진다.

## 스피커 아트

`Assets/Art/UI/Speaker/1.aseprite`는 등장 때 한 번, `2.aseprite`는 대사가 표시되는 동안 원본 프레임 순서와 속도로 반복한다. 다음 문장을 클릭해도 발화 동작이 이어진다. 스피커 옆 픽셀 음파는 발화 박자에 맞춰 커지며 사라진다. `BroadcastWaves.png`는 21×24 투명 Point Sprite다. 세 에셋은 기존 경로와 메타 파일을 유지해 교체한다.

문구·순서·강조 대상은 [ShelterDialogue 명세](../DataSpecs/ShelterDialogue.md)에서 편집한다.

그래픽실과 개발률, 수면실, 가방, 시계의 표시를 [플레이 화면](../Images/BunkerTutorial.jpg)에서 볼 수 있다. [방송·입력 검증 기록](../DataHistory/20261123-bunker-tutorial.md).
