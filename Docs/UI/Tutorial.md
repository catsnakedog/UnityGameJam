# 복도 튜토리얼

타이틀의 ‘튜토리얼’ 버튼은 전용 Tutorial 씬으로 연결된다. 파밍 시작 복도의 같은 배경과 좌측 셔터를 사용한다. 1920×1080 고정 화면에서 실제 파밍과 같이 왼쪽 시작 지점에서 복도 높이가 화면에 맞는다. 개발 방 소개에서 복도 전체로 줌아웃하고 입구 안내에서 셔터로 확대한다. 화면 네 면의 검은 반투명 패널이 대상 밖을 가린다. 가방과 시계는 벙커 HUD와 같은 스프라이트·모양·위치로 보여 준다.

| 방송 구간 | 표시 |
|---|---|
| 방송 시작 | 파밍 시작 지점 |
| 개발 방 소개 | 복도 전체 |
| 벙커 입구 | 복도 왼쪽 셔터 확대 |
| 물자 | 우측 하단 가방을 펼쳐 초콜렛과 노트북 예시를 표시 |
| 일정 | 좌측 상단 시계와 범례 |
| 마무리 | 파밍 시작 구도로 복귀 |

공유 UI/speaker_tags의 640×360 Aseprite 두 개를 Assets/Art/UI/Speaker에 반입한다. 1은 등장 1회, 2는 방송 동작이다. 스피커는 등장부터 발화까지 화면 오른쪽 끝에 배치한다. 말풍선 배경을 상하·좌우로 뒤집어 오른쪽 위 꼬리가 스피커 하단을 가리키게 하고, 대사 글자는 정방향으로 표시한다. ShelterSpeech 프리팹의 9슬라이스와 Neo둥근모 글꼴을 재사용한다. 클릭 또는 탭 한 번에 한 문장이 진행되고 마지막 문장의 다음 클릭은 FarmingRules의 기본 인물로 Farming을 시작한다. 설정 창이 열린 동안 방송 입력과 애니메이션을 멈춘다.

문구·순서·강조 키는 [벙커 대사 명세](../DataSpecs/ShelterDialogue.md)에서 관리한다. 아트 변경은 기존 Aseprite 경로와 태그를 유지해 재임포트한다.

## 플레이 검수

타이틀 버튼에서 14개 문장과 설정 창의 입력 차단을 확인했다. 1920×1080에서 복도·입구·가방, 1440×1080의 16:9 게임 영역에서 시계·마지막 문장을 캡처했다. 각 문구가 CSV와 일치하고 말풍선 안에 들어갔다. 마지막 클릭 이후 Farming의 Preparing 단계와 기본 인물 person_01을 확인했다.

입구 확대와 말풍선 배치는 [실제 플레이 화면](../Images/TutorialEntrance.png)에서 볼 수 있다. 발화 Aseprite의 첫 프레임 길이를 시험 변경한 뒤 복구했다. 클립 재생 시간이 1.21초에서 1.18초로 바뀌었다가 1.21초로 복구됐으며 씬의 클립 참조는 유지됐다.
